# ROLL-OUT-GAME

Roll Out suggests activities based on a dice roll. The Restaurants filter opens a directory of A-grade restaurant inspection records with metro, NYC borough, neighborhood, and search filters.

NYC listings come from the public NYC DOHMH Restaurant Inspection Results dataset. Its records are historical inspection results, so check the inspection date and the official source for a restaurant's current grade. Other metros are listed in the selector, but are not shown until an official A-grade data source is connected; the app does not infer or convert grades from other inspection systems.

Run locally with `npm run dev`. Build the site with `npm run build`.
