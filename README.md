# ROLL-OUT-GAME

Roll Out suggests activities based on a dice roll. New York City users choose a borough on the next screen after sign-up. The Restaurants filter can use browser location to find nearby official health inspection records in NYC and Chicago, with a selectable search radius. NYC records include A-grade inspections and borough/neighborhood filters; Chicago records report inspection outcomes rather than letter grades. Cuisine defaults to all food types where the official dataset provides cuisine information.

The directory is not a complete national inventory of restaurants or foodservice outlets. City inspection datasets differ, may include historical records, and do not use one shared grade system. Other metros are listed in the selector, but are not shown until a verified official inspection feed is connected. The app does not infer or convert grades from other inspection systems. Check each listing's inspection date and the linked official source for its latest status. Location is requested only when the user chooses the nearby-search button.

Run locally with `npm run dev`. Build the site with `npm run build`.
